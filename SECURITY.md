# Security Policy

## Scope

Security reports concerning Security Event Detector are welcome.

This project is designed for authorized defensive security analysis and
educational use.

## Reporting a Vulnerability

Please avoid publicly disclosing a suspected vulnerability before there is
an opportunity to review it.

When reporting an issue, include:

- A clear description of the issue
- The affected component or file
- Reproduction steps
- Expected behavior
- Actual behavior
- Relevant logs or stack traces where appropriate

Do not include passwords, API keys, private keys, access tokens, or other
sensitive information.

## Safe Use

Only use this project against systems and logs you are authorized to inspect.

The project does not grant permission to access, monitor, test, modify, or
interfere with third-party systems.
