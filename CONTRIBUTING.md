# Contributing

Thanks for contributing to Security Event Detector.

## Development Requirements

- Python 3.10+
- No external Python packages are currently required

Run the complete test suite before submitting changes:

```bash
python3 -m unittest discover -s tests -v
```

## Code Expectations

Keep changes focused, readable, tested, and defensive in nature.

New security behavior should normally include automated tests.

Do not add functionality intended for unauthorized access, exploitation, automated retaliation, or destructive remediation.

## Pull Requests

Please describe what changed, why it changed, how it was tested, and any compatibility considerations.
