# Security Event Detector v1.0.0

Security Event Detector v1.0.0 is the first stable portfolio release.

## Included

- Synthetic authentication log support
- Ubuntu authentication log parsing
- SSH brute-force detection
- Multi-account authentication detection
- Sensitive sudo detection
- Account-management detection
- Configurable detection thresholds
- Event normalization
- Detection correlation
- Explainable risk scoring
- Confidence assessment
- Investigation findings
- Recommended investigation actions
- JSON and Markdown reports
- Real-time log following
- Rolling event windows
- Duplicate alert suppression
- Streaming incident correlation
- Persistent live incident storage
- Incident lifecycle management
- Automated tests

## Security Boundary

The project is intended for authorized defensive analysis and educational use.

## Future Development

Potential future releases may add:

- Dashboard visualization
- Database-backed persistence
- Additional telemetry formats
- Additional detection rules
- Threat-intelligence enrichment
- Improved log rotation handling
- Advanced false-positive analysis
- Deployment automation
